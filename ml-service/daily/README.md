# Daily Position Monitoring Workflow

## Overview

The daily signals workflow monitors all active positions and generates position-aware trading signals. It checks stop-loss levels, target prices, calculates unrealized P&L, and produces a comprehensive daily report.

## Prerequisites

- Database with active positions in the `positions` table
- ML predictions available in `predictions` table for the target date
- Market price data in `daily_bars` table

## Usage

### Basic Usage

Run the daily monitoring for the default user (user_id=1) and today's date:

```bash
cd ml-service/daily
python daily_signals.py
```

### Custom Date

Generate report for a specific date:

```bash
python daily_signals.py --date 2026-02-02
```

### Save to File

Save report to a file instead of printing to console:

```bash
python daily_signals.py --output reports/daily_2026-02-02.txt
```

### Full Example

```bash
python daily_signals.py --user-id 1 --date 2026-02-02 --output ../logs/position_report_2026-02-02.txt
```

## Report Sections

### 1. Position Summary

For each active position, displays:

- Entry details (price, quantity, date)
- Current market price
- Unrealized P&L (amount and percentage)

### 2. Risk Management

- **Stop Loss**: Distance from current price, triggered status
- **Targets**: T1, T2, T3 distances and reached status

### 3. ML Predictions

Multi-horizon predictions (1d, 5d, 10d) showing:

- Expected return (p50)
- Confidence level
- Risk range (p10 to p90)

### 4. Trading Signal

Position-aware signal generated by ML system:

- Signal type: BUY_NEW, BUY_MORE, SELL, SELL_PARTIAL, HOLD, HOLD_NONE
- Strength (0.0 to 1.0)
- Reasoning

### 5. Alerts Summary

Highlights critical conditions:

- 🚨 Stop loss triggered
- 🎯 Target prices reached
- ⚠️ Missing predictions
- Action signals (SELL, SELL_PARTIAL, BUY_MORE)

## Scheduling (Optional)

### Linux/Mac (cron)

Add to crontab to run daily at 8 AM:

```bash
crontab -e
```

Add line:

```
0 8 * * * cd /path/to/ml-service/daily && python daily_signals.py --output ../logs/daily_$(date +\%Y-\%m-\%d).txt
```

### Windows (Task Scheduler)

1. Open Task Scheduler
2. Create Basic Task
3. Set trigger: Daily at 8:00 AM
4. Action: Start a program
5. Program: `python`
6. Arguments: `daily_signals.py --output ../logs/daily.txt`
7. Start in: `d:\Program\Source\Nonobeam\stock-trading\golang-stock-trading\ml-service\daily`

## Troubleshooting

### No predictions available

**Symptom**: Report shows "Predictions not available"

**Solution**: Run prediction generation first:

```bash
cd ml-service
python -m inference.predictor --ticker VCI --date 2026-02-02
```

### Current price not found

**Symptom**: Report shows "Current price not available"

**Solution**: Ensure `daily_bars` table has recent data for the ticker:

```sql
SELECT * FROM daily_bars WHERE ticker = 'VCI' ORDER BY date DESC LIMIT 5;
```

### Signal generation fails

**Symptom**: Report shows "Signal generation failed"

**Solution**: Check logs for detailed error. Common causes:

- Database connection issue
- Invalid prediction data format
- Position data corruption
